# Assets

- `dist/assets/logo.png`: original Step in Style logo supplied by the user, copied without editing.
- `dist/assets/hero.webp`: generated original studio artwork featuring abstract cobalt glass and orange forms with ivory headphones.
- `dist/assets/headphones.webp`, `dist/assets/lamp.webp`: generated illustrative demo product imagery. These are not verified supplier photographs and are never seeded into the live database.
- Interface icons: inline stroke paths following familiar Lucide-style icon geometry.
- Typography: optional Google Fonts import for DM Sans and Manrope, with local system sans-serif fallback. The website remains usable if the font service is unavailable.
